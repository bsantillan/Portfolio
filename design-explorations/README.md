# Exploraciones de diseño

Mockups estáticos (hero + caso IoT). Abrí cada `index.html` en el navegador; las capturas están en `*/capturas/` (390 y 1440 px, claro y oscuro). `_antes/` tiene el sitio actual.

| | A · Hoja técnica | B · Tablero | C · Transcripción |
|---|---|---|---|
| Metáfora | Plano / datasheet de ingeniería | Tablero eléctrico con diagrama unifilar | Paper académico + voz del lector de pantalla |
| Paleta | Papel + tinta + naranja de seguridad | Chapa gris / grafito + amarillo de señalización + cobre | Papel blanco + tinta + rojo de corrector |
| Tipografía | Barlow Condensed / IBM Plex Mono / Source Serif 4 | Archivo (eje de ancho) / Atkinson Hyperlegible Next + Mono | Newsreader / Spline Sans Mono |
| Onda | Banda bajo el nombre, el cursor cambia la 3.ª armónica | "Acometida" que alimenta los circuitos, se deforma con el scroll | Figura con ejes (Fig. 1), como un gráfico de paper |
| Accesibilidad | Toggle "Ver estructura" superpone anotaciones | Toggle-interruptor "Estructura" | La transcripción es la columna derecha, visible por defecto |
| Riesgo | Bajo-medio | Medio | Alto |

Todas las fuentes se van a self-hostear en la implementación (acá usan Google Fonts solo para el mockup).
